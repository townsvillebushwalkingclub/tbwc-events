🏔️ TBWC Events Embed Widget

This example shows how to embed the Townsville Bushwalking Club events widget on your website.

📋 Implementation Steps

1. Add the Container

Add this HTML where you want the events to appear:

<div id="tbwc-events"></div>

2. Include the Script

Add this script tag to your HTML head or before the closing body tag:

<script src="https://your-vercel-deployment.vercel.app/embed-snippet.js"></script>

Important: Replace your-vercel-deployment with your actual Vercel deployment URL.

3. Complete Example

Here's a complete example of how to implement it:

<!DOCTYPE html>
<html>
<head>
    <title>Townsville Bushwalking Club</title>
</head>
<body>
    <h1>Welcome to Townsville Bushwalking Club</h1>
    
    <!-- Events will appear here -->
    <div id="tbwc-events"></div>
    
    <!-- Include the events script -->
    <script src="https://your-vercel-deployment.vercel.app/embed-snippet.js"></script>
</body>
</html>

🎨 Customization

Styling Options

The widget comes with built-in styles, but you can customize it by adding CSS:

<style>
/* Customize the widget appearance */
.tbwc-events-container {
    max-width: 800px; /* Make it wider */
    background: linear-gradient(135deg, #4facfe 0%, #00f2fe 100%); /* Different colors */
}

.tbwc-event-item {
    background: rgba(255,255,255,0.2); /* More transparent */
}
</style>

Configuration

You can modify these settings in the script:

  • MAX_EVENTS: Number of events to display (default: 5)
  • DAYS_AHEAD: How many days ahead to show events (default: 90)
  • API_BASE_URL: Your Vercel deployment URL

📱 Features

  • Responsive Design: Works on desktop and mobile
  • Automatic Updates: Shows the latest events from your API
  • Error Handling: Gracefully handles API errors
  • Loading States: Shows loading spinner while fetching data
  • Facebook Integration: Links to your Facebook page
  • Beautiful Design: Modern gradient design with hover effects

🔧 Technical Details

API Endpoint

The widget fetches events from:

GET https://your-vercel-deployment.vercel.app/api/events/{year}/{month}

Example: https://your-vercel-deployment.vercel.app/api/events/2025/8

Data Format

The API returns events in this format:

{
  "success": true,
  "data": [
    {
      "id": "event-id",
      "name": "Event Name",
      "description": "Event description",
      "start_time": "2025-08-15T09:00:00.000Z",
      "formatted_date": "Friday, August 15, 2025",
      "formatted_time": "9:00 AM",
      "attending_count": 12,
      "interested_count": 25,
      "place": { "name": "Location Name" }
    }
  ]
}

🚀 Deployment

To use this widget:

  1. Deploy your Next.js app to Vercel
  2. Update the API_BASE_URL in the script to your Vercel URL
  3. Add the HTML and script to your website
  4. Test to make sure events are loading correctly
